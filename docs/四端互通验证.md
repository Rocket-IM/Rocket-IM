## 测试控制契约

这是仅用于本机测试的HTTP控制通道，非产品Relay、消息API或SDK网络能力。控制器只绑定`127.0.0.1`，Android模拟器通过`10.0.2.2`访问。应用配置为`ROCKETS_INTEROP_URL`、`ROCKETS_INTEROP_RUN_ID`、`ROCKETS_INTEROP_ENDPOINT_ID`；Swift通过进程环境、Kotlin通过同名小写Intent参数`interop_url`/`interop_run_id`/`interop_endpoint_id`、Flutter通过同名大写Dart编译定义、浏览器通过URL查询`interop_url`/`interop_run_id`/`interop_endpoint_id`提供。仅测试应用允许本机明文HTTP，不改变SDK或产品安全配置。

统一路径为`/interop/{run_id}/{endpoint_id}`：

- `POST /ready`：对象含`run_id`、`endpoint_id`、`sdk_version`、`platform`；正常初始化后登记，控制器返回`{"ok":true}`。
- `GET /next`：200返回下一条命令；没有命令时最多等待10秒后返回204，应用继续轮询；只允许一个命令在执行。
- `POST /result`：提交精确命令结果，控制器验证run、端和command均匹配，返回`{"ok":true}`。不接受未知、重复或错绑定响应来完成当前操作。

命令为`{"run_id":"...","command_id":"cmd000001","op":"new","handle":"a","args":{}}`。`args`始终为字符串到字符串的对象；字节参数及字节结果采用标准Base64，空字节为`""`。命令ID为字符串，长度/数量有限。成功返回`{"run_id":"...","endpoint_id":"...","command_id":"cmd000001","ok":true,"value":null}`，字节操作的`value`为Base64字符串。失败返回`ok:false`和`error:{"origin":"sdk","code":"invalid_argument","device_poisoned":false,"message":"..."}`；测试装置自己的输入/运行错误使用`origin:"harness"`，不能充当SDK拒绝证据。Swift/Kotlin从实际公开错误类型提取字段；Flutter/浏览器从SDK返回的固定错误文本提取，无法解析时不得猜测错误码。落盘记录只保留已校验的分类、状态和字节摘要，不保存未知异常正文。

| op | args / 返回 |
|---|---|
| `new` | `service_id`、`account_id`、`device_id`；新建独立对象，返回null，handle不得覆盖现存对象。 |
| `identity` / `key_package` | 无参数；调用公开接口，返回字节Base64。 |
| `create_group` | `conversation_id`、`peer_account_id`、`peer_device_id`、`peer_identity_key`、`key_package`；返回Welcome Base64。 |
| `join_group` | `conversation_id`、`creator_account_id`、`creator_device_id`、`creator_identity_key`、`welcome`；返回null。 |
| `encrypt` / `decrypt` | 分别为`plaintext` / `ciphertext`；返回对应字节Base64。 |
| `close` | 调用公开close但保留handle以验收关闭后拒绝，返回null。 |
| `drop` | 调用close并移除handle/资源，返回null。 |
| `shutdown` | 关闭并清理全部对象，返回null后结束轮询。 |

客户端只保留最多32个handle，操作顺序由同一串行任务控制。HTTP失败使测试明确失败；没有结果、超时或进程退出不能返回PASS。不对有状态密码命令自动重做；测试失败通过新进程/新对象建立下一次独立实验。单请求/响应上限1MiB，测试报告只保留字节长度和SHA-256。合成明文仅用于验证其往返相等，不模拟或收集真实用户消息。
