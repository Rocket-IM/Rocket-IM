更新：2026-09-15。范围已确认；产品功能开发、完整测试和发布验收均待执行。阶段 0 局部探针结果见[密码方案验证](密码方案验证.md)，不代表下列功能已验收。

第一期 21 项、第二期 12 项。重叠能力共用实现，编号保持独立。交付物见 [交付物与技术栈](交付物与技术栈.md)，工程步骤见 [开发路线与检查清单](开发路线与检查清单.md)；工程阶段不改变产品归期。

## 共同规则

- 第三方安装公开 SDK、部署独立 Service，通过 API 接入自己的账号与业务；无需 fork、修改方案源码、导入内部包或直接读写 IM 表。各端 Demo 均有登录注册。
- Dart/Flutter、Swift、Kotlin、TypeScript 四种 SDK 语言交付必须独立发布和互通；文中的“四端”沿用这一交付简称，不代表四种操作系统。TypeScript 以 macOS、Windows 桌面客户端接入为主，浏览器为次，交付 SDK API 与对应的 Rust 运行产物；桌面运行时和绑定方式待验证，不将 Rust 核心转译为纯 TypeScript。使用者无需 Rust/Cargo 或绑定生成器，仍正常构建自己的应用；Rust crate 用户正常使用 Rust 工具链。
- Service 使用 PostgreSQL；四种 SDK 语言交付的 SQLite（包括 TypeScript 桌面与浏览器目标）由 Rust 唯一持有并管理。宿主只通过公开 SDK 异步读写，全部进入统一读写线程或浏览器等价串行执行上下文；桌面绑定、浏览器落盘适配及线程分配数量待验证或商议，详见[端侧存储与附件管理](端侧存储与附件管理.md)。
- Rust 的全部数据库读写必须在显式事务内执行，单次只读查询、恢复读取和迁移中的数据/结构读写也不例外。同一业务一致性单元共用事务，读事务正常结束后才返回结果；初始化与维护命令按专项文档核对，不默认开放事务外读写。
- 多设备默认开启，可关闭；Service 执行限制，关闭时选择保留设备并撤销其他设备权限和必要密钥。
- 多账号并存登录、接收消息；凭证、密钥、库、队列、游标、缓存、回调和推送按服务实例与账号隔离。移动端后台通过系统推送和恢复同步补齐，不承诺 Socket 常驻。
- E2EE 默认开启，可按部署策略选择非 E2EE；会话创建时固定模式，第一期变更需新建会话，不自动迁移旧明文或历史密钥。禁止加密失败或版本不兼容时静默降级。
- 仅成员设备持有解密私钥的“公钥加密群”也属于 E2EE，具体机制待验证。非 E2EE 仍使用 HTTPS/WSS，并明确标识服务器可能读取内容；元数据可见范围需公开。
- 登录、设备授权与历史恢复分开。撤销不收回旧副本；以协议确认的新密码状态为边界，被撤销方即使取得此后生成的新密文，也不能用旧密钥解密。变更前在途消息另定规则，不仅依赖本地时间。

## 第一期：21 项

01—11 为原始功能，12—21 为补充能力。每项同时满足下表与统一验收。

| 编号 | 功能 | 范围与验收要点 |
|---|---|---|
| 01 | 登录与注册 | 各端 Demo 注册、登录、退出可用；第三方能使用已有身份取得 IM 凭证，无需修改源码。凭证生命周期复用 16。 |
| 02 | 文字消息 | 单聊/群聊发送、接收、展示；编码和长度限制明确。跨端互发正确，重复请求不产生重复消息，可靠性复用 12。 |
| 03 | 图片、视频、语音消息 | 选择/录制、预览/播放，定义格式、尺寸、时长和引用。支持格式跨端可用；E2EE 原件、缩略图、封面端侧加密，解密信息通过 E2EE 消息传递；流程复用 17。 |
| 04 | 多设备 | 多个授权设备收发并同步，包括自己从其他设备发送的消息。关闭后仅保留指定设备，其余不能重新连接或获得不应获得的新消息与密钥；管理复用 15。 |
| 05 | 多账号 | 同设备多个账号保持登录并接收消息，可切换操作账号。切换、退出、延迟事件和通知均不串号；生命周期复用 16。 |
| 06 | E2EE 可选、默认开启 | Service 与 SDK 拒绝违背会话模式的发送，SDK 校验设备身份、密钥变化与协议版本，UI 展示安全状态。正文、自定义消息和附件遵循同一模式；不支持或失败明确报错，禁止降级。 |
| 07 | 会话列表 | 单聊/群聊分页、增量更新、名称、头像、摘要、时间、未读、免打扰和安全状态。E2EE 摘要端侧生成；同步后列表、排序和未读正确，无重复会话。 |
| 08 | 会话功能 | 创建/打开有权限会话、时间线、输入发送、附件和详情；展示发送、网络、信任和解密错误。页面重建不重复启动引擎、不丢持久状态。 |
| 09 | 用户与好友管理 | 资料、用户发现/搜索、好友列表和关系事件；支持业务资料接入。用户身份与好友关系独立，修改后跨设备同步；关系流程复用 18。 |
| 10 | 群聊 | E2EE/非 E2EE 建群、收发、成员查询和群事件；创建时固定模式。跨端互通，身份验证有效，未授权设备不能取得群密钥；权限复用 19。 |
| 11 | 用户/群详情及操作 | 详情、私有备注、删好友、退群、举报。备注不改对方公开资料；UI 与 API 权限一致，确认、错误及操作后的列表/关系状态一致。 |
| 12 | 消息可靠性与状态 | 发送中、失败、本地已保存、Service 已接受、已送达分别表达；公开已读回执可配置。重连、补拉、稳定 ID、幂等、去重和顺序可验证；发送密文与密码状态一致保存，接收原事件与下载游标共同保存，有效消息、去重、密码状态及处理游标一致提交。入库后才发对应数据成功回调，失败独立报错；本地保存不等于 Service 接受，Socket 写成功不等于送达。 |
| 13 | 历史与会话状态 | 历史分页、增量、未读/已读位置跨端同步、免打扰、删会话、清空记录。明确设备/账号范围；删除不等于撤回，不承诺删除对方副本，补拉不错误恢复已删状态。 |
| 14 | 离线推送 | 推送注册/更新/注销、账号绑定、通知开关、免打扰和通知定位。挂起、账号交错及凭证失效后不串号或越权；E2EE 正文不交给推送服务，供应商通过配置/适配接入。 |
| 15 | 设备管理与历史恢复 | 设备列表、名称、最近活动、登录提醒、授权、撤销和身份变化提示。新设备不自动取得旧密钥；换机、重装、全部设备丢失按授权迁移或加密备份策略处理，无法恢复明确提示。旧钥解不开撤销后新状态密文，保留设备正常收发。 |
| 16 | 账号隔离与登录生命周期 | 凭证续期/失效、单账号退出/移除/重登及本地清理；对接业务封禁、删除和权限变化。A 退出后延迟任务不能写 B，其他账号继续按系统规则收消息。 |
| 17 | 附件完整流程 | Rust 管理编码/解码、加密/解密、上传/下载任务及持久状态，宿主可配置最大附件工作数，整个处理链受控。完成进度、取消、失败重试、播放、格式/大小/时长/配额、完整性和下载鉴权；清理临时、失败、孤儿、过期文件及明文缓存。断网、重复、取消和越权结果明确，文件与数据库提交可恢复；E2EE 衍生文件不交给服务端明文处理。 |
| 18 | 好友关系闭环 | 申请、接受、拒绝、重复申请、拉黑/解除；确定陌生人消息、删友单双向、历史保留和共同群内影响。并发关系变更和发送权限一致。 |
| 19 | 群权限与成员变更 | 群主/管理员/成员、邀请、审批、移除、转让、解散、禁言；定义新人历史、退出和解散后的访问。必要密码状态更新前不得按旧授权分发新密钥；旧成员解不开新状态密文，覆盖在途、并发变更和离线设备。 |
| 20 | 举报处理闭环 | 举报用户/群/消息、原因、说明、证据、状态、管理处理与审计。E2EE 用户确认披露内容、对象及上下文，仅提交所选范围；证据访问/保留/真实性规则明确，导出明文不自动等于可信证据。 |
| 21 | 解决方案接入 | 服务端 SDK、用户映射、凭证、群/设备/配置 API、自定义消息、事件、错误和兼容说明；Webhook 验签、去重、重试。独立业务工程只用发布包与 Service 完成接入，回调不默认输出 E2EE 明文。 |

## 第二期：12 项

以下能力不作为第一期发布条件；实现前确定时间窗口、权限和指标。

| 编号 | 功能 | 范围与验收要点 |
|---|---|---|
| 01 | 消息编辑 | 作者权限、时间窗口、版本与编辑标识；重复、乱序和离线后结果一致。E2EE 修改内容保持加密，无权限编辑被拒绝。 |
| 02 | 消息撤回 | 权限、时间窗口、提示与跨端同步；覆盖重复、先收到撤回及附件已缓存，不承诺收回导出或截图副本。 |
| 03 | 消息转发 | 文字/附件转发到有权限目标，明确来源、批量和限制；按目标会话重新保护，接收方不依赖原群密钥。转入非 E2EE 前提示并确认，重试不重复。 |
| 04 | 引用回复 | 引用、摘要和原消息定位；删除、撤回、未同步或无权限时正确占位，不绕过历史权限或通过服务端明文摘要泄露 E2EE 内容。 |
| 05 | 表情回应 | 添加、取消、参与者和计数；重复/乱序后各端一致，权限有效，E2EE 事件按约定保护。 |
| 06 | 收藏 | 收藏、取消、分页、跨端访问；确定副本/引用、加密恢复及原消息删除/撤回/附件过期行为。账号隔离，不绕过原会话授权。 |
| 07 | 全文搜索 | 搜索、定位、索引更新与权限过滤；E2EE 默认端侧索引。按约定语言、样本和性能指标验收，编辑/撤回/清理后索引正确，不向 Service 上传 E2EE 正文。 |
| 08 | 输入状态 | 开始、停止、超时、频控、隐私开关及多设备聚合；断网/退出后不长期残留，不向无权限账号推送。 |
| 09 | 在线状态 | 在线/离线/最近活动、隐私和多设备聚合；异常掉线按约定时限更新，API/UI 权限一致。区别于第一期本人设备活动信息。 |
| 10 | 跨端草稿 | 跨端同步、并发冲突、删除与恢复；账号隔离，旧草稿不错误复活，内容按冲突规则保留。E2EE 草稿不明文同步。 |
| 11 | 语音转文字 | 进度、取消、重试、语言和结果保留；按样本验证质量/耗时。明确端侧/云端处理，未经有效授权不向云端上传 E2EE 语音明文，结果按会话规则保护。 |
| 12 | 音视频通话 | 呼叫、接听、拒绝、取消、超时、挂断、权限和弱网恢复；确定单/群通话、平台和多设备接听规则，避免重复接听。信令/媒体/中继单独验证；声明 E2EE 必须证明服务端无法解密媒体并验证成员变更。 |

## 统一验收与发布门槛

各项均需公开 SDK/API、必要 Demo 流程和可重复证据，不能只在 Demo 私有代码中实现。

2026-09-15 交付目标澄清：下列交付、互通、存储与生命周期要求均须按声明的目标系统验收，TypeScript 的 macOS、Windows 桌面目标不能用浏览器结果代替。既有浏览器最小包和隔离 POC 仅保留其已执行范围，不构成桌面 SDK 完成证明；浏览器专项检查继续保留。此次澄清不增减一期 21 项、二期 12 项或下列检查项。

- [ ] **交付：**独立业务工程仅消费实际发布包和 Service 产物，完成原账号登录与功能接入；四端无需 Rust/生成器。覆盖声明支持的真机、模拟器、ABI、浏览器和 Release 构建。
- [ ] **互通：**覆盖单聊/群聊、E2EE/非 E2EE、文字/图片/视频/语音、多设备/多账号组合，确认默认值和安全标识正确。
- [ ] **同步：**自己的消息同步到其他设备；跨端未读/已读、删除与历史权限正确。账号切换、退出、凭证失效、延迟回调和通知均不串号。
- [ ] **存储与回调：**四端经公开 SDK 完成 SQLite 读写；全部访问进入显式事务，验证单次只读查询、同一快照组合读取、库内原子提交、迁移回滚、事务复用及读写/提交失败或取消后的收尾。验证统一串行执行、读事务结束后返回结果、提交后数据成功回调、独立错误通道和事务外派发，活动游标不跨 FFI；回调中再次查询不死锁、不阻塞 UI。回调丢失及订阅重连可查库恢复，查询与订阅衔接不漏变化；协议确认与双游标不依赖 UI 回调。
- [ ] **浏览器持久化：**验证 SQLite 关闭重开、重启、多标签页访问、配额不足及存储被清理后的行为，账号隔离与恢复符合约定；持久化不可用时明确失败，不静默改用内存数据库。
- [ ] **附件任务：**验证宿主配置的最大工作数约束完整处理链，取消、重试、断网、账号退出和恢复不绕过限额；耗时处理不占数据库读写线程，文件与数据库提交中断不产生伪成功或不可恢复的任务状态。
- [ ] **故障：**断网、丢确认、重复/乱序、慢客户端、上传取消、数据库失败和服务重启后，结果可恢复或明确失败；未持久化不报成功，约定保留期内已接受消息不丢失、游标不漏消息、资源不无界增长。
- [ ] **安全：**验证设备授权/撤销、关闭多设备、成员变化、群权限与附件鉴权；向被撤销方提供新状态密文，旧钥仍不能解密。区分变更前在途消息，合法成员正常工作。
- [ ] **隐私：**验证 E2EE 正文、附件及衍生文件不经正常流程泄露给 Service、日志、推送；举报只披露确认范围，管理访问受控并有审计。
- [ ] **恢复与升级：**验证换机、重装、全部设备丢失的既定策略；执行 SDK/Service 升级、库迁移、备份恢复。仅声明实测兼容范围，失败有恢复方案。
- [ ] **第一期出口：**21 项全部通过；独立接入者完成聊天、附件、多设备、多账号、群聊、离线恢复和一次升级。不得把已确认功能直接列为“不适用”。
- [ ] **第二期出口：**12 项逐项通过且一期无回归；验证乱序编辑/撤回/回应、跨端收藏/搜索/草稿、隐私状态、识别授权及独立通话安全。混合版本明确提示不支持能力，不静默丢内容或降级。
- [ ] **发布阻断：**无未解决的串号、越权、静默降级、密钥泄露或已接受消息无法按约定恢复的问题。数量、时间、质量、性能和支持范围事先锁定，不因失败临时降低标准。

## 证据与待定细节

每项记录：**期数/编号、Service/核心/平台包/协议/数据版本、系统与设备、负载和网络、前置状态、操作步骤、预期/实际结果、脱敏证据位置、结论、日期与执行者**。

文档/静态检查、构建打包、自动化测试、跨端运行、安全与容量验证分开报告。未执行不得勾选；文档完成不代表功能完成。公开证据不得包含真实凭证、私钥和无关隐私。

实施前锁定下列细节，不以“待定”为由移出已确认分期：

- 密码协议、许可证、设备验证、备份/恢复、撤销生效点和在途规则。
- 账号/设备上限、保留设备选择、新设备/新成员历史和数据保留期。
- Demo 注册、用户发现、好友/拉黑/群权限、已读默认值及删除同步范围。
- 文件格式/大小/时长/配额、清理、推送供应商和平台限制。
- SQLite 库绑定、浏览器落盘与多标签页协调、读写线程分配数量、回调派发和查询/订阅恢复接口；不改变 Rust 数据库所有权。
- 最大附件工作数的计数单位、作用域、总/分项限额、默认值和运行中调整规则；具体命名及数值待商议。
- 支持平台、分发仓库、版本兼容及各期数量/时间/质量/性能指标。
